# コラム100本の計画

リオ鍼灸サロンのドメインを強化し、検索からの訪問と予約を増やすためのコラム計画です。
作成日：2026-11-08（Search Console の過去3か月のデータをもとに作成）

## 進め方のルール

- **公開ペースは週1〜2本**。短期間に大量公開すると、Google の「大量生成されたコンテンツの不正使用」と判断されるおそれがある
- **1本ずつ、お店ならではの情報を入れる**（実際のメニュー・料金・施術の流れ・院長の考え方）。料金や店舗情報は config から自動で表示する
- **公開前にオーナーが内容を確認する**。書いた人（個人名）は記載しない
- 表現は「〜と言われています」「個人差があります」の形。効果を言い切らない（あはき法）
- 健康に関する記事（「注意」欄に ⚠ があるもの）は、症状によって医療機関の受診をすすめる一文を入れる。病名の治療をうたわない
- お客様の声・体験談は、実際の声で掲載の許可があるものだけを使う。作らない
- 記事の作り方：`config/columns.php` に追加し、本文を `resources/views/components/column/columnN.blade.php` に書く。`public/sitemap.xml` にも追加する
- 同じ検索を狙う記事を2本作らない（同じテーマは1本にまとめて、内容を充実させる）

## 優先度の考え方

- ★★★：Search Console で表示回数が多い／順位があと一歩（5〜15位）の言葉。予約に近い
- ★★：検索されていて、メニューにつながる
- ★：記事どうしをつなぎ、専門性を厚くするための記事
