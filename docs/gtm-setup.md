# 予約ボタンなどのクリックを Google Analytics で計測する設定手順

この手順書は、リオ鍼灸サロンのホームページで「予約ボタンが押された」「メニューが見られた」などを Google Analytics（GA4）で数えられるようにするためのものです。パソコンのブラウザで、上から順番に進めてください。

- Googleタグマネージャー（GTM）のコンテナID：**GTM-WTVF47M**
- 作業時間の目安：30〜40分
- 設定した結果が Google Analytics のレポートに出るまで：24〜48時間

---

## なぜ設定が必要なのか

ホームページは、ボタンが押されるたびに「LINEのボタンが押されました」といった合図を出しています。ところが、その合図を Google Analytics へ届ける設定が GTM にまだありません。そのため今は、予約ボタンが何回押されたかがわかりません。

この手順で「合図を受け取って Google Analytics に送る」設定を1つ作ります。

---

## ホームページが出している合図（イベント）の一覧

### 予約・相談に関する合図
| イベント名 | いつ出るか | キーイベントにするか |
|---|---|---|
| `reservation_square_click` | Squareの予約リンクが押されたとき | **する** |
| `reservation_hotpepper_click` | HotPepperの予約リンクが押されたとき | **する** |
| `reservation_line_click` | LINEのリンクが押されたとき | **する** |
| `reservation_phone_click` | 電話番号が押されたとき | **する** |
| `begin_booking` | 「予約する」ボタンを開いたとき、予約ページへのリンクが押されたとき | しない（予約の手前の行動のため） |

### そのほかの合図
| イベント名 | いつ出るか |
|---|---|
| `select_menu` | メニューの詳しいページへのリンクが押されたとき |
| `select_content` | コラムから「リオについて」「初めての方へ」などのページへのリンクが押されたとき |
| `hotpepper_reviews_click` | 「HotPepperで口コミを見る」が押されたとき |
| `view_menu` | メニューの欄が画面に表示されたとき |
| `view_access` | アクセスの欄が画面に表示されたとき |
| `view_staff` | スタッフ紹介の欄が画面に表示されたとき |
| `view_faq` | よくある質問の欄が画面に表示されたとき |
| `click_google_map` | ページ内の地図が押されたとき |

`view_` で始まる合図は、その欄が**実際に画面に表示されたとき**に1回だけ出ます。「そのページのどこまで読まれたか」を知るために使います。

### 合図と一緒に送られる情報（パラメータ）
| 名前 | 中身 | 例 |
|---|---|---|
| `booking_provider` | どこで予約しようとしたか | `square`、`hotpepper`、`line`、`phone` |
| `cta_position` | ページのどこにあるボタンが押されたか | 下の表を参照 |
| `menu_name` | どのメニューのボタンか | `美容鍼灸 70分` |
| `customer_type` | 新規向けか、再来店向けか | `new`、`repeat` |
| `staff_name` | スタッフの名前（今は使われていません） | — |

### `cta_position`（ボタンの場所）の一覧
| 値 | 場所 |
|---|---|
| `header` | ページ上部の「予約する」メニュー |
| `header_nav` | ページ上部のメニューの「予約」 |
| `header_sns` | ページ上部のLINEアイコン |
| `mobile_fixed` | スマホの画面下に固定されたボタン |
| `footer` | ページ下部の電話番号 |
| `footer_sns` | ページ下部のLINEアイコン |
| `home_campaign` | トップページの限定メニュー |
| `home_recommended_menu` | トップページのおすすめメニュー |
| `home_final_cta` | トップページ下部の予約案内 |
| `home_access` | トップページのアクセス欄の電話番号 |
| `home_sns` | トップページのSNS欄のLINE |
| `home_reviews` | トップページの口コミ欄 |
| `menu_page` | メニューページの「ご予約はこちら」 |
| `campaign_page` | キャンペーンページの「ご予約はこちら」 |
| `reserve_page` | 予約ページ |
| `first_visit_page` | 「初めての方へ」ページ |
| `column_mid` | コラムの途中 |
| `column_end` | コラムの最後 |
| `error_page` | エラーページ（※今はエラーページで計測が動いていません。下の「注意」を参照） |

## 手順1：Googleタグマネージャーを開く

1. https://tagmanager.google.com/ を開き、Google Analytics と同じGoogleアカウントでログインします
2. コンテナの一覧から **GTM-WTVF47M** をクリックします
3. 左側のメニューの「**タグ**」をクリックし、Google Analytics のタグ（種類が「Googleタグ」や「Google アナリティクス: GA4 設定」となっているもの）がすでにあるか確認します
   - ある場合：そのまま手順2へ進みます
   - ない場合：今は別の方法で Google Analytics が入っている可能性があります。その画面のスクリーンショットを送ってください

## 手順2：Google Analytics の「測定ID」を確認する

1. Google Analytics を開き、左下の歯車（**管理**）をクリックします
2. 「データの収集と修正」→「**データストリーム**」をクリックし、表示されたウェブサイト（rio-salon.com）をクリックします
3. 右上に出ている **G-** で始まる文字（測定ID）をメモします

## 手順3：送る情報の「変数」を作る（5つ）

合図と一緒に届く情報（どのボタンか、どこで予約しようとしたか）を GTM が読み取れるようにします。

1. GTMの左側のメニューで「**変数**」をクリックします
2. 下の「ユーザー定義変数」の「**新規**」をクリックします
3. 上の「変数の設定」をクリックし、「**データレイヤーの変数**」を選びます
4. 「データレイヤーの変数名」に `booking_provider` と入力します
5. 左上の名前を `DLV - booking_provider` に変えて、「**保存**」を押します
6. 同じ手順で、次の4つも作ります

| 変数の名前 | データレイヤーの変数名 |
|---|---|
| `DLV - cta_position` | `cta_position` |
| `DLV - menu_name` | `menu_name` |
| `DLV - customer_type` | `customer_type` |
| `DLV - staff_name` | `staff_name` |

## 手順4：合図を受け取る「トリガー」を作る（1つ）

1. 左側のメニューで「**トリガー**」をクリックし、「**新規**」を押します
2. 左上の名前を `サイトのイベント（予約・メニューなど）` にします
3. 「トリガーの設定」をクリックし、「**カスタム イベント**」を選びます
4. 「イベント名」に、次の1行をそのまま貼り付けます

   ```
   ^(begin_booking|reservation_(square|hotpepper|line|phone)_click|hotpepper_reviews_click|select_menu|select_content|view_(menu|access|staff|faq)|click_google_map)$
   ```

5. すぐ下の「**正規表現一致を使用**」に**チェックを入れます**（これを忘れると動きません）
6. 「このトリガーの発生場所」は「**すべてのカスタム イベント**」のままにして、「**保存**」を押します

## 手順5：Google Analytics に送る「タグ」を作る（1つ）

1. 左側のメニューで「**タグ**」をクリックし、「**新規**」を押します
2. 左上の名前を `GA4 - サイトのイベント` にします
3. 「タグの設定」をクリックし、「Google アナリティクス」→「**Google アナリティクス: GA4 イベント**」を選びます
4. 「測定 ID」に、手順2でメモした **G-** で始まる文字を入力します
5. 「イベント名」の右にあるブロックのアイコンを押して、「**Event**」を選びます。欄に `{{Event}}` と入ればOKです
   - 一覧に「Event」がない場合は、変数の画面の「組み込み変数」→「設定」で「Event」にチェックを入れてください
6. 「**イベント パラメータ**」を開き、「パラメータを追加」で次の5行を入れます

| イベント パラメータ | 値 |
|---|---|
| `booking_provider` | `{{DLV - booking_provider}}` |
| `cta_position` | `{{DLV - cta_position}}` |
| `menu_name` | `{{DLV - menu_name}}` |
| `customer_type` | `{{DLV - customer_type}}` |
| `staff_name` | `{{DLV - staff_name}}` |

7. 下の「トリガー」をクリックし、手順4で作った `サイトのイベント（予約・メニューなど）` を選んで、「**保存**」を押します

## 手順6：プレビューで動作を確かめる

公開する前に、本当に動くかを確かめます。

1. GTMの右上の「**プレビュー**」を押します
2. 別のタブで「Tag Assistant」が開くので、`https://rio-salon.com/` を入力して「Connect」を押します
3. ホームページが別のウィンドウで開きます。そこで次の操作をしてみます
   - 「予約する」を押す
   - LINEのボタンを押す（LINEが開いたら閉じてかまいません）
   - メニューのページを開いて、下までスクロールする
4. Tag Assistant の画面に戻り、左側の一覧に `begin_booking` や `reservation_line_click` が出ていることを確認します
5. その項目をクリックし、「Tags Fired（動いたタグ）」に `GA4 - サイトのイベント` が入っていれば成功です

あわせて、Google Analytics の「管理」→「**DebugView**」を開くと、同じ合図がリアルタイムで届いているのが見えます。

うまくいかない場合は、Tag Assistant の画面のスクリーンショットを送ってください。

## 手順7：公開する

1. GTMの右上の「**送信**」を押します
2. 「バージョン名」に `予約ボタンなどのクリック計測を追加` と入力します
3. 「**公開**」を押します

これで、本番のホームページで計測が始まります。

## 手順8：Google Analytics で「キーイベント」に設定する

予約に関わる合図を「キーイベント（ゴール）」にすると、レポートで予約につながった数が見やすくなります。

**公開してから24時間ほど待ってから**行ってください。合図が一度も届いていないと、一覧に出てこないためです。

1. Google Analytics の「管理」→「データの表示」→「**イベント**」を開きます
2. 次の4つの行の右にある「**キーイベントとしてマーク**」をオンにします
   - `reservation_square_click`
   - `reservation_hotpepper_click`
   - `reservation_line_click`
   - `reservation_phone_click`

`begin_booking` は予約の手前の行動なので、キーイベントにはしません。

## 手順9：ボタンの場所などをレポートで見られるようにする

`cta_position`（どこのボタンか）などをレポートに表示するには、Google Analytics 側でも登録が必要です。

1. Google Analytics の「管理」→「データの表示」→「**カスタム定義**」を開きます
2. 「**カスタム ディメンションを作成**」を押します
3. 次の3つを1つずつ登録します（「範囲」はすべて「**イベント**」）

| ディメンション名 | イベント パラメータ |
|---|---|
| ボタンの場所 | `cta_position` |
| 予約先 | `booking_provider` |
| メニュー名 | `menu_name` |

---

## 注意

- **ここで数えられるのは「予約ボタンが押された回数」です。実際に予約が完了した数ではありません。** 実際の予約数は、Square・HotPepper（SALON BOARD）・LINEの記録で確認してください
- Google Analytics にもともとある「click」（外部サイトへのリンクのクリック）の数は、これからも記録されます。今回の設定と同じクリックを別の名前で数えているだけなので、2つを足さないでください
- エラーページ（存在しないページを開いたときの画面）では、今は計測のプログラムが読み込まれていないため、`error_page` の合図は届きません
- 設定を変えたあと、レポートに反映されるまで24〜48時間かかることがあります
