## 1. 背景と目的

### 背景
- 現在のサイトは情報面ではかなり揃っている（お悩み別メニュー、選ばれる理由、初回来店の流れ、アクセス、スマホ用の固定予約ボタン、4種類の予約経路）。
- 一方で、オーナーは課題を **「見た目が古い・素人っぽい」** と感じている。
- そのため、来店したお客様がリピートする理由である **人柄・接客・雰囲気** が、来店前のサイト訪問者に伝わっていない。

### 目的
**ビジュアルの質と信頼感を高め、「顔と身体をまとめて任せられる、話しやすい鍼灸師のサロン」であることを初めての訪問者に伝えること。その結果として、新規のWeb予約とLINE相談を増やす。**

## 2. ターゲット

### メインターゲット
**美容鍼に興味がある女性**

| 項目 | 想定 |
|---|---|
| 年代 | 30〜50代 |
| 居住エリア | 水戸市および近郊（車で来店） |
| お悩み | たるみ、ほうれい線、むくみ、くすみなど、お顔のエイジングサイン。あわせて肩こりや疲れやすさなど、身体の不調もある |
| 心理状態 | 美容鍼は初めてか経験が少なく、「痛くないか」「どんな人が施術するのか」「高くないか」に不安がある |
| 行動 | Instagram、Google検索・マップ、HotPepperで比較してから公式サイトを見に来る。主にスマホで閲覧 |

### 実際の顧客層（HotPepper Beautyの予約比率。2026-11-07時点）
| 性別 | 比率 | 年代の内訳 |
|---|---|---|
| 女性 | 85% | 20代 17% ／ 30代 28% ／ 40代 33% ／ 50代以上 22% |
| 男性 | 13% | 30代 93% ／ 50代以上 7% |
| 未設定・その他 | 2% | — |

- 想定ターゲット（30〜50代女性）と一致している。女性の83%が30代以上で、中心は30〜40代（61%）
- 50代以上の女性が22%いる → 文字の大きさ・読みやすさを優先し、電話での予約・問い合わせも残す
- 20代女性（17%）はブライダル目的の来店がある → ブライダル向けメニューにふれておく
- 男性が13%（ほぼ30代）いる → 女性向けに寄せすぎない。「男性の方も」と一言添える
- 注意：HotPepper経由の予約だけの集計で、Square・LINE・電話の予約は含まれない

### ペルソナ（例）
> 42歳、水戸市在住の会社員。最近、写真に写る自分の顔のたるみが気になり始めた。美容鍼に興味はあるが、鍼が怖く、どのサロンを選べばいいかわからない。慢性的な肩こりもある。Instagramでリオを見かけ、公式サイトで「どんな人が、どんな雰囲気でやっているのか」を確認したい。

## 3. ゴールとKPI

### コンバージョン（訪問者にしてほしい行動）
1. **新規のWeb予約**（Square / HotPepper）
2. **LINEでの相談**（予約にまだ迷っている人の受け皿）

> 電話予約は残すが、主な導線にはしない。

### KPI（成果の測り方）
GTM（`GTM-WTVF47M`）とGoogle Analyticsで計測する。

| 指標 | 内容 | 目標 |
|---|---|---|
| 予約ボタンのクリック率 | Square / HotPepperへの遷移数 ÷ セッション数 | 改善前と比べて向上 |
| LINE相談のクリック率 | LINEリンクへの遷移数 ÷ セッション数 | 改善前と比べて向上 |
| トップページの直帰率 | トップだけを見て離脱した割合 | 改善前と比べて低下 |
| 美容鍼メニューページの閲覧数 | 美容鍼関連ページへの遷移数 | 改善前と比べて向上 |

> **改善前の数値（ベースライン）を、デザイン変更の前に必ず記録しておく。** 数値がないと効果を比較できない。具体的な目標値は、ベースラインを確認してから決める。

### ベースライン（GA4、2026-08-09〜2026-11-06の90日間）
| 項目 | 数値 |
|---|---|
| アクティブユーザー | 752人（スマホ634人＝84%、PC112人、タブレット6人） |
| アプリ内ブラウザ（Instagram・LINEなど）から | 114人（Safari in-app）＋ Android Webview 39人 |
| トップページ（/） | 表示459回、ユーザー268人、1人あたり平均エンゲージメント時間 **約29秒** |
| コラム（/column/column1） | 表示420回、ユーザー**390人**（トップより多い）、1人あたり1.08ページ、平均約48秒 |
| 美容鍼灸メニュー（/menu/menu1） | 表示226回、ユーザー130人、平均約45秒 |
| 予約ページ（/reserve） | 表示54回、ユーザー42人 |
| 外部リンクのクリック（click） | 80回、55人（予約・LINE等への遷移を含むと思われる） |
| キーイベント（コンバージョン） | **0件（未設定）** |

**計測の課題**
- キーイベントが未設定のため、予約数・LINE相談数を数えられていない
- [public/js/analytics.js](../public/js/analytics.js) が送っている独自イベント（予約ボタンのクリック、`view_menu` など）が、GA4に1件も届いていない。GTM側でGA4へ送る設定がされていない可能性が高い
- `data-gtm-view` はページを開いた時点で発火する作りのため、設定しても「そのセクションまで読まれたか」は測れない。リニューアル時に、画面に表示されたときに発火する仕組みへ変える

## 4. コンセプトと伝えるメッセージ

### お店の強み（優先順）
1. **顔と身体を同時にケアできる**：新規を集める一番の強み
2. **人柄・接客・雰囲気**：リピートされる一番の理由
3. **漢方の知識があり、東洋医学の観点で身体の根本から見られる**：他のサロンとの差別化ポイント
4. （裏付け）国家資格・20年以上の臨床経験（HotPepperの「歴20年以上」に表記を統一。2026-11-07）
5. **鍼灸だけでなくエステもできる**：フェイシャルエステティシャン・化粧品検定1級・アロマ検定1級の資格。セルキュア、酵素ピーリング、美容液導入、炭酸パック、リンパオイル、ヘッドスパ、漢方浴など

### コンセプト案
**「顔の悩みを、身体の根本から。話しやすい鍼灸師が、東洋医学でまるごとケア。」**

### 訪問者に伝わってほしい印象
- 落ち着いていて清潔感がある
- 施術者が親しみやすく、相談しやすい
- 美容サロンらしい華やかさと、鍼灸院としての専門性・信頼感を両立している
- 「チェーン店」ではなく「人」に会いに行く感覚

### 伝える順番（トップページの物語）
1. **共感**：お顔の悩みは、身体の不調ともつながっている
2. **解決策**：顔と身体を同時にケアする美容鍼
3. **根拠**：漢方・東洋医学の知識と、20年以上の臨床経験
4. **人**：施術者の顔、人柄、お店の雰囲気
5. **安心**：初回の流れ、料金、お客様の声、よくある質問
6. **行動**：Web予約 / LINEで相談

## 5. 現状の課題（サイトを確認した所見）

| # | 課題 | 内容 | 優先度 |
|---|---|---|---|

## 7. 非機能要件・制約

| 項目 | 要件 |
|---|---|
| 対応端末 | **スマホを優先して設計する**。PCとタブレットにも対応 |
| SEO | 既存のURL、title、meta description、構造化データ（JSON-LD）を維持する。URLを変える場合は301リダイレクトを設定する |
| 計測 | GTMのタグと、予約・LINEボタンのクリック計測（`analytics.js`）を壊さない |
| 表示速度 | 画像はWebPで配信し、適切なサイズに圧縮する。PageSpeed Insightsのモバイルスコアを改善前より下げない |
| アクセシビリティ | 文字と背景のコントラストを確保する。画像にaltを付ける。タップしやすいボタンサイズ（44px以上）にする |
| 店舗情報 | 住所、電話、営業時間などは `config/salon.php` の一か所で管理する現在の仕組みを維持する |
| 口コミ | 掲載元の規約確認と投稿者本人の許可が取れるまで、口コミ本文は転載しない |
| 開発 | Gitでブランチを切って作業し、ローカル（`php artisan serve`、MAMPのPHP 8.0）で確認してから本番に反映する |

## 9. 実装状況（2026-11-07時点、ブランチ `renewal/phase1`）

トップページを「親しみやすい案」のワイヤーフレームどおりに実装済み（本番未反映）。

- 構成：ファーストビュー → ご挨拶 → こんなこと、ありませんか？ → 大切にしていること・できること → おすすめメニュー → お客様の声 → はじめての方へ → お店のこと・アクセス → 最後のお手紙
- ファイル：`resources/views/index.blade.php`、`resources/views/components/top/*`、`public/css/top.css`
- 文言・メニュー・口コミは `config/top.php` で管理。店舗情報は従来どおり `config/salon.php`
- 写真は `public/img` の既存写真を仮で使用（about, ceo, course23, course3, course27, course8, location2, location6）。撮影後に差し替える
- フェーズ2（2026-11-07）：全ページを新デザインに移行。共通レイアウトは `layouts/renewal`
  - メニューは `config/menus.php`、キャンペーンは `config/campaign.php` で管理（Squareの予約ページ 2026-11-07時点に合わせた）
  - `campaign/first` は `campaign/term#first` へ301リダイレクト（はじめての方の料金は menus.php の first_price から自動表示）
  - 旧デザインの部品・CSSは削除。エラーページ（errors/）は外部ファイルに依存しない作りのため従来のまま
- 旧トップページの部品（`components/index/*`）は削除せず残している

**許可・確認待ちのためスキップしたもの**
- 口コミ本文：`config/top.php` の `reviews` で `approved` を `true` にしたものだけ表示。許可が取れるまでは「お客様の声」の見出しと、HotPepperの評価・リンクのみ
- 季節のおすすめメニュー：`config/top.php` の `seasonal` を設定すると表示（今は非表示）
- （解決）エイジング美容鍼（顔＋全身）100分はSquareでは冬キャンペーン限定のため、トップページのおすすめは通常メニューの「美容鍼灸（顔＋全身）90分 14,300円」に差し替え
- （解決）Squareでも初回料金（美容鍼灸70分 10,500円）で予約できることを確認（2026-11-07）。トップページの「Webで予約する」はSquareのまま
